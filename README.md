Judul     : Data penyewaan/rental barang  
Descripsi : implementasikan multi linked-list yang memodelkan data toko rental dan data 
barang beserta relasi keduanya. Suatu toko bisa banyak menyewakan barang. Dan suatu 
barang bisa di sewa oleh banyak toko.  
Fungsionalitas :  
a. Penambahan data toko.  
b. Penambahan data barang.  
c. Penentuan relasi toko dan barang yang disewa (dan sebalikknya).  
d. Menghapus data toko.  
e. Manghapus data barang.  
f. 
Menampilkan data keseluruhan toko beserta data barang yang disewakan.  
g. Menampilkan data barang yang disewa oleh toko tertentu.  
h. Menampilkan data toko yang menyewakan barang tertentu.  
i. 
Menampilkan data toko yang paling lengkap barang sewanya dan yang paling sedikit.
